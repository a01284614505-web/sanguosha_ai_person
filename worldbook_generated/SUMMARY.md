## 💡 如何使用这些数据

### 1. 作为AI世界书注入
```python
# 在AI决策时注入相关武将技能
def build_worldbook(heroes_in_game):
    worldbook = []
    for hero in heroes_in_game:
        hero_data = load_json(f"heroes/{hero.faction}/{hero.id}.json")
        worldbook.append(hero_data["worldbook"])
    return "\n\n".join(worldbook)
```

### 2. 作为游戏引擎规则参考
```python
# 加载伤害结算流程
damage_rules = load_json("rules/damage_system.json")
# 按照 damage_rules["damage_flow"]["steps"] 实现结算
```

### 3. 作为前端显示数据
```javascript
// 加载卡牌数据显示UI
fetch('/worldbook_generated/cards/basic_cards.json')
  .then(r => r.json())
  .then(cards => renderCards(cards))
```

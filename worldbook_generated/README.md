# 三国杀世界书自动生成文档

## 📖 说明

本目录包含从以下来源整理的游戏规则和数据：

### 数据来源（公开资料）
1. **维基百科** - 三国杀标准版完整牌表和武将列表
2. **BWIKI** - 界限突破武将技能描述
3. **无名杀开源项目逻辑分析** - 游戏机制理解（非代码复制）

### 法律说明
- ✅ 游戏规则、武将名称、技能描述等属于公开信息，整理成JSON合法
- ✅ 参考开源项目的**游戏逻辑**（如触发时机、结算顺序）合法
- ❌ 不直接复制无名杀的JavaScript代码
- ❌ 不使用官方的美术素材（需使用开源替代）

### 生成策略
**方案A（逻辑分析）**：从无名杀源码理解触发机制、事件总线设计
**方案B（公开整理）**：从BWIKI/维基百科提取武将/卡牌数据

## 📂 目录结构

```
worldbook_generated/
├── rules/              # 游戏规则
│   ├── game_flow.json       # 回合流程
│   ├── identity_modes.json  # 身份局规则
│   ├── damage_system.json   # 伤害结算
│   └── card_usage.json      # 用牌规则
├── heroes/             # 武将数据（27将）
│   ├── wei/                 # 魏势力
│   ├── shu/                 # 蜀势力
│   ├── wu/                  # 吴势力
│   └── qun/                 # 群雄
├── cards/              # 卡牌数据（108张）
│   ├── basic_cards.json     # 基本牌
│   ├── trick_cards.json     # 锦囊牌
│   └── equipment_cards.json # 装备牌
└── terms/              # 游戏术语
    └── glossary.json        # 术语表
```

## 🎯 使用方法

1. 将生成的JSON文件复制到 `~/sanguosha_tavern/data/` 目录
2. 游戏引擎会自动加载这些数据
3. AI决策时会注入相关的世界书条目

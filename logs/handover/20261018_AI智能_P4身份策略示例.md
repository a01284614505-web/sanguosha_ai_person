# AI 智能提升 P4：身份策略示例库

上游：[定稿方案](20261018_1435_AI智能提升与称号系统方案.md) 第 8 节及附录 A；分支 `feat/ai-smart-p4`，依赖 P3。

- `strategy_examples/` 下四身份 JSON + common.json，包含 21 条身份经验与3条拆谎提醒。保留“条件→可选做法”、具体话术、可以想别的打法的口吻，策略不是规则。README 说明用户如何增改。
- `strategy_library.py` 只依据自己身份、公开轮次/座次/血线/存活人数/公开敌对事件筛选；每次随机抽3–4条本身份建议，再给一小段别人常用骗术。未用对手隐藏身份或暗牌选择示例。
- **先想后看是真正的两次请求**：先输出独立局势、笔记、打法和理由（无操作字段）；再给经验示例，问是否有更好做法，最后才选操作。草稿不执行、不落笔记/打法；第二次结果才解析提交，两个请求均进真实 usage / prompt 快照。
- 成本范围：仅有多个候选的模型 AI 出牌决策增加一次请求；规则 AI、单候选、响应/选择/聊天不增加。最多一次参考复核，无递归尝试；失败走原规则 AI 回退。比 P3 多一请求是方案“先想后看”的实现成本，真实缓存/延迟/用量待实战日志评估。
- 新增4项专项测试：数据有效与随机小样本、局势过滤、两次真实请求顺序及只执行最终选择、旁路跳过与故障无重试。

验证：全量 pytest **755 passed，50 subtests passed**；前端 JS、diff 检查通过。所有原测试保留。真实话术、打法、多阶段调用的用户体验待统一实战验收；未调用外部模型 API。watchdog、无懈链、L0 分层继续保持。

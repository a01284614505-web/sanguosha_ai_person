## 检测结果

### 首次提取：失败并已修复

原因：noname JS 的 `list` 最后一项带尾逗号。

```text
json.decoder.JSONDecodeError: Expecting value: line 112 column 2
```

修复为只剥离最外层数组尾逗号后重跑成功。

### 数量与构成：通过

```text
standard: 108 张
类型: {'basic': 53, 'equipment': 19, 'trick': 36}

extra: 53 张
类型: {'basic': 32, 'equipment': 7, 'trick': 14}
```

标准牌堆 36 张 trick 包含 31 张普通锦囊和 5 张延时锦囊。

### 来源逐项一致与 ID 唯一性：通过

```text
standard: source_match=True unique_ids=True count=108
extra: source_match=True unique_ids=True count=53
fire_sha=5
thunder_sha=9
```

逐张投影 `suit/rank/source_name/nature` 与 noname 原始数组顺序完全一致。

### 关键牌抽查：通过

```text
standard_sha_spade_7_1
standard_taoyuan_heart_1_1
standard_shandian_spade_1_1
```

### Python 编译：通过

`python -m py_compile scripts/extract_noname_deck.py` 输出为空，退出码 0。

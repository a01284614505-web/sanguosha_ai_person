## Objective（可验收目标）

对应总计划 O12、O13，按当前仓库改写：

1. `frontend/game.html` ≤ 200 行纯结构：无内联 `<style>`，无大段内联 `<script>`；引用外部 `css/main.css` + `css/game.css` + `js/game_main.js`（响应弹窗若拆出则再引 `js/game_response.js`）。
2. `rg -c "#d4af37" frontend/game.html` = 0；抽出的 `game.css` 中 `#d4af37` / `#f5e6d3` / `#2a1f1a` / `#8a7a6a` 全部改为 `main.css` 已有变量（`--gold`、`--text-light`、`--bg-card`、`--text-muted`）。
3. 10+ 个对局页全局裸变量收进单一 `GameUI` 命名空间；HTML `onclick` 事件模型保留，被引用函数挂 `window`。
4. 删除对局页「伪造整局配置」（含 `apiKey:'test_key'`）、删除默认武将 `liubei`/`max_hp:4` 硬编码；配置不合法则提示并回大厅，不自造对局。
5. 删除 `game.html` 与 `settings.html` 的牌堆别名映射 `{test_deck:'standard',complete_deck:'standard'}`；前端只传原始 `deck_id`，归一化交给服务端 `DeckManager.normalize_deck_id`。
6. 大厅 8 人局 / 2v2 / 斗地主三个按钮置灰，点击提示「后续阶段开放」；删除这三种模式的身份构成映射。只保留 5 人身份局可选。
7. 对局页对手区、自己区、选将页头像改为 `<img src="assets/heroes/{hero_id}.jpg">`，`onerror` 回退为首字；27 将齐全时显示立绘。
8. `python -m pytest -v` 当前全量（预期 83）全过；`python scripts/check_frontend_js.py` 通过；`git diff --check` 通过。
9. 真实浏览器冒烟：大厅建局 → 选将（可见头像）→ 对局（对手/自己可见头像）→ 出牌 → 至少一次响应弹窗 → 主动结束 → 结算页。规则 AI 自动对局跑到非 `aborted` 的胜负。

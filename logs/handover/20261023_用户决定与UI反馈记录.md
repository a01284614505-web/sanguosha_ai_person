## 3. UI 反馈（对 2026-10-23 设计画布的意见）

### 3.1 必须保留的原有设计

- 体力用**阴阳鱼**勾玉。
- **卡牌沿用之前贴近官方的设计**：插画、左上花色点数、右上类型角标、底部牌名。不要改成大号书法字的极简牌。
- **技能按钮沿用之前的设计**：长条、加重边框；可发动时高亮，绿色或金色都可以。技能经常需要点按发动，原设计的交互优势要保留。
- **电脑端聊天保留右侧边栏**（席间 / 战报两个标签）。侧边栏在电脑上非常方便。

### 3.2 要改的方向

- **整体气质**：游戏内部不需要简洁风，能引导注意力到牌局上就行。要更"游戏"：写实一点、有竞争感、金碧辉煌，"群雄争锋应该有财力展示"。现有暗色版太沉闷；新稿又太像精美的 PPT，边框太柔和、没有修饰。
- **背景**：千里江山配色可以，但要**降低明度和饱和度、柔和过渡，不要硬边山线**。背景是烘托牌局的，不能当主角、不能抢视野。
- **饱和度**：三个方向都偏高，加上界面过于简洁，所以有网页感。
- **阶段栏（电脑端）**：放在**靠近自己的位置**，不要放在顶部。方便看，也更有动画感。
- **出牌区**：千里江山稿里牌随意摆放的凌乱感很好；但**多张牌时的排布**要设计好。牌与牌之间要有**堆叠感**（烽火稿也要）。
- **倒计时秒数**的显示方式（烽火稿）可以保留。
- **方向 B（烽火夜战）**：配色再深一些，偏**深褐色**。中间圆桌的高亮边框去掉，原 GPT 设计的圆桌含义不需要的话，可以改成**夜幕下的江山**，同样遵守背景不抢戏的要求。
- **方向 C（宣纸朱墨）**：不考虑，太简洁。
- **手机端**：技能部分太占地方。底部区域应该用来显示**更多信息**，包括判定区挂了什么牌、装了什么装备（装备不止四格，还有宝物等）。技能沿用之前的设计。

### 3.3 Claude 的改动幅度

用户意见：新稿改动"稍微有些太大，在很多交互上失去了原本的优势"。后续 UI 工作的原则是**在原有交互结构上提升质感**，不推翻布局与交互。

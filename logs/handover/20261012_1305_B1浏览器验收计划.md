## B1 范围

B1 保证真人请求具备可追踪的请求 ID、即时输入回执、重复与过期请求隔离，以及对局结束后的等待器唤醒和副作用门控。浏览器应正确呈现并关闭通用响应面板，非法输入应在原截止时间内允许重试。

本仓库已有 B1 引擎、服务器与旧 UI 实现，以及自动场景 `tests/test_b1_input_lifecycle.py`。本计划补齐真人浏览器操作的验收记录；不把 Node 语法检查或 WebSocket 冒烟等同于浏览器验收。

## 浏览器验收步骤

- [ ] 创建五人身份局，确认真人回合正常展示。
- [ ] 触发真人响应请求，确认弹窗显示请求内容、可用选项和倒计时。
- [ ] 选择合法选项，确认弹窗关闭、对局继续，收到 `accepted` 回执。
- [ ] 对多选请求提交重复索引或非法索引，确认收到拒绝说明；弹窗在原截止时间内重新打开，剩余倒计时不重置。
- [ ] 请求已应答后重复提交，确认不会再次执行效果；旧请求不能影响后续新请求。
- [ ] 在响应弹窗打开时主动结束对局，确认弹窗关闭、进入结算页，迟到的响应不产生游戏效果。
- [ ] 在出牌动画等待中结束对局，确认没有继续结算已中止的动作。

每一步需记录浏览器、页面尺寸、操作结果和控制台错误；失败时附复现步骤。真人点击结果由浏览器运行现场确认，不能以脚本输出代填。

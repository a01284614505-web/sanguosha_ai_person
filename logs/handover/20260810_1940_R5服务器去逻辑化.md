## 4. 验收中发现并修正的问题
1. 重写服务器时曾把 `HTTP_PORT` 临时写成 `888`；对照架构、启动器和历史端口后恢复为等价的 `8_888`。
2. 主动结束首次专项脚本注册了同步 lambda，导致引擎打印事件处理器 await 异常；换成真实异步处理器后重跑，得到无事件异常的唯一性结果。
3. 规则 AI 首次冒烟读取了不存在的 `GameState.turn_count`；对局本身已正常结束为 `draw`，修正验收脚本后复验 `game_over=True`、单次 `game_end`。
4. 最终组合检查首次在 `ARCHITECTURE.md` 检出一处行尾空格；清理后 `git diff --check` 通过。
5. 牌堆 GET 门面初接线时遗漏原有异常转 HTTP 500 包装；已补回并通过真 HTTP 专项。
6. Bash 安全分类服务间歇返回临时不可用；未强行绕过，稍后重跑所有必要检查并取得成功输出。

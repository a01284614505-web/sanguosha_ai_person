# 拉取模型列表与骅骝修正

日期：2026-10-17 16:00（+08:00）。执行模型 `claude-opus-5-5`。进入提交 `e0821c8`（main），分支 `feat/model-list-hualiu`。

## 改动

- **拉取模型列表**：大厅“配置座上宾”、局内“调整 AI”、托管“自定义模型”三处的模型名称输入框旁新增【拉取】按钮。点击后服务器向所填服务商请求可用模型，列表显示在输入框下方，点选填入，打字可过滤，仍可手填任意模型名。
  - 新模块 `game_engine/model_catalog.py`：OpenAI 兼容 `GET {base}/models`（Bearer）；Claude 加 `x-api-key`/`anthropic-version`；Gemini 原生地址用 `x-goog-api-key` 且只保留 generateContent 模型；地址末尾的 `/chat/completions` 自动去掉。
  - 新接口 `POST /api/models`。只接受 http/https 地址、不跟随重定向、10 秒超时、返回体上限 4MB；错误转成可读提示（Key 无效 / 不支持拉取 / 超时等），Key 不写日志、不回传。
  - 局内“调整 AI”时 Key 可留空：服务器按本局 `game_id` + 座位、且档案 `profile_id` 一致时沿用已保存的 Key。
  - HTTP 服务改为 `ThreadingHTTPServer`，拉取等待外部 API 时不阻塞页面加载。
- **骅骝修正**：军争的骅骝是 +1 马（防御马）。牌堆数据 `sub_type` 本来就是 `plus_horse`，但 `card_table.py`、`card_text.py`、`card_info.js` 误写成 -1。三处已改正，单一真相源与牌堆数据一致。
- `.form-grid` 加 `align-items: start`，展开模型列表时同行的下拉框不再被拉高。

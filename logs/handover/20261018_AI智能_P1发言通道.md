# AI 智能提升 P1：独立发言与公开事实校验

上游：[定稿方案](20261018_1435_AI智能提升与称号系统方案.md) 第 5 节；依赖 P0，分支 `feat/ai-smart-p1`。

- 出牌和响应 JSON 不再要求、解析或转发 chat_message；删除响应旁路与出牌阶段的顺带发言。free 字段从引擎入库、广播与协议清理。聊天只通过调度器产生，保持每轮上限及原节奏。
- 聊天临时尾巴提示全桌可见、可说谎/跳假身份/诈唬/沉默；JSON 顺序为意图、他人观感、台词，附自己的完整笔记及可用打法。
- `chat_facts.py` 只匹配完整的“号位→号位（或主公）→动作→次数”陈述，对照公开 ledger。超过账本次数、明确总计不符或否认已发生事件时拦截；引述、条件、疑问、局部轮次、手牌与身份话术放行。“做过一次”不排除多次，不拦这种少报。
- 拦截不上聊天桌、不计发言次数；服务端脱敏警告 + blocked_chat 局后日志，下一次聊天提示此前冲突（不额外调用）。仅作弊局发送 CHAT_REJECTED 专用事件，作弊思考面板可见；服务器再次检查作弊闸门。
- protocol.py 定义新事件并生成 protocol.js；ws_client、game_main、logs_page 接展示。非作弊局不广播任何拦截提示。
- 更新旧测试为新通道契约（不删除测试），新增 16 项专项测试：静默拦截、私有纠错、相同事实、无法识别/推测放行、隐私和旧模型字段忽略。

验证：全量 pytest **735 passed，50 subtests passed**；前端语法、协议同步与 diff 空白检查通过。P0 的独立座次映射保持。watchdog、无懈链深度、L0 分层未改。实战台词质量待用户统一跑局验收。

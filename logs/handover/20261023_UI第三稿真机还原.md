# UI 第三稿：真实对局页按效果图还原（Opus 亲自改）

日期：2026-10-23
分支：`feat/ui-v3-polish`（基于 main 38f31f2）

## 起因

PR #32（Haiku 接线）合并后，用户反馈：“这和给我的效果图完全不一样，太丑。”
对照效果图（`logs/design/20261023_牌桌第三稿原型.html`）后，差距集中在下面几项：

1. 武将框外圈是势力色（红/蓝），而不是粗鎏金框；角花小，而且缩在框里。
2. 背景远山被裁掉（SVG 居中裁切），牌桌显得平。
3. 处理区是一排分开的小牌，每张都带说明，而效果图是一摞交替倾斜的牌，最新一张最大、带橙光。
4. 电脑端操作条宽、居中、悬在牌桌里，而效果图是贴在手牌上方的紧凑面板。
5. 缺左上信息牌（身份存活数、目标）、金圈圆按钮、底部金线与菱形。
6. 字体是无衬线黑体；效果图全程用宋体系衬线字。
7. 手机竖屏我的区域布局与效果图不同。

## 做法

新增一层样式 `frontend/css/table_v3.css`，在 game.css 之后加载，只管外观和位置，不碰交互。另有少量标记调整。

**game.html**

- 左上信息牌加两行：`#idCounts`（身份存活数）、`#goalText`（目标）。
- `#actionBar` 从牌桌挪进我的区域 `.hand-wrap`，位于阶段栏和手牌之间。所有 id 不变。
- 远山 SVG 改为顶对齐：`xMidYMin slice`。

**game_main.js**

- `seatFrameHTML`：立绘上加 `.s-shade` 暗角；自己的名牌右侧写“N号 · 你”。
- `seatNameHTML`：座位号包在 `<b>` 里。`textContent` 仍是“N号 名字”，测试不受影响。
- `renderMyArea`：拆出“装备区 / 判定区”两个小标题，另有手机用的“装备 · 判定”；判定区每项显示菱形标记加牌名。
- `renderPhaseTrack`：显示“X 的回合 / 你的回合”。
- `putOnTable`：保留 5 张，按出牌序号加 `tilt-N` 倾角，旧牌不跟着换角度；说明写进 `title`。
- `aimLines`：改成虚线弧线加箭头，淡金渐到橙红，弧线朝牌桌中央鼓起，约 1.4 秒后淡出。SVG 改为 `position: fixed`，指向自己时能画进底部区域。
- `renderHUD`：按模式计算身份存活数。5 人局和 8 人局用总配置减去已亮明身份的阵亡者，其他模式不显示。另外按自己的身份写出目标。
- `showBubble`：自己的气泡挂在武将框那一列。

**table_v3.css 按断点组织**

- 全局（换皮）：
  - 鎏金框，角花 24px 并伸出框外。
  - 印章金圈、名牌渐变、名签整宽药丸、装备小签。
  - 当前回合的大范围暖光、牌摞、指向线。
  - 底部金线和菱形、装备槽、阶段金珠、技能长条（原型 `.sk`）。
  - 席间：双金线，深色气泡，圆头像。
- 电脑（宽 ≥ 901 且高 ≥ 601）：
  - 三列：装备区 204、中列、我的武将 150。
  - 中列从上到下是“阶段栏 → 操作条 → 手牌”。
  - 武将框在上，技能长条在下。技能有 4 个及以上时改成两列短条。
- 高 ≤ 820 的电脑（1280×720）：各部件收紧，上排两席向两侧让位，牌摞缩小。
- 非电脑：操作条浮在我的区域上方。
- 手机竖屏：按原型 `renderMobile` 排布。
  - 四席一排。
  - 我的区域：左边武将 86×116；右边“装备 · 判定”两列网格加技能一排；下方整行手牌（68px）。
  - 阶段栏和手牌数浮在操作条上一行。
- 手机横屏：沿用 game.css 的紧凑排布，只换皮；装备、判定压成一列小槽。

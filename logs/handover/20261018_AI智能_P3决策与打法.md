# AI 智能提升 P3：先想后选与跨回合打法

上游：[定稿方案](20261018_1435_AI智能提升与称号系统方案.md) 第 7 节；分支 `feat/ai-smart-p3`，依赖 P2。

- 决策 JSON 按 situation → notes → plan → how_others_see_me → reasoning → target_ids → action_index 顺序生成；去掉“简短理由”及引擎已能兜底的重复防御语句，强调将注意力用于赢。
- L0 保持与玩家无关、所有 AI 逐字相同，继续共用两条稳定 system 前缀与原压缩机制。只调整通用语气，身份目标进入 L2。新增 `tactical_context.py`：每种身份的胜败条件、中间目标、暴露代价，允许说谎、诈唬、冒险，同时保留公开事实底线。
- plans 独立于会话窗口存储，每次出牌/响应/选择/聊天重新注入；校验 style/why、过滤标记及长度，允许改打法并写原因，阵亡后不可改。作弊面板可见，每轮认知快照带 plan，日志额外有 plan_snapshots，日志页显示。
- 根据公开账本提供“你的处境”：自上一轮以来对自己动手的不同人数、对主公的净敌意/友好排名（并列口径写清）。不读取其他人暗牌或隐藏身份作结论。
- 理由存储上限提升到 1000 字，响应与选牌同样先比较收益代价，再输出索引；thinking 默认值不改。
- 新增 7 项专项测试覆盖字段顺序、四身份目标、计划独立于压缩/阵亡冻结/快照、公开反馈与隐私。原前缀不变性测试显式关闭字符/条数触发，隔离“未压缩的追加”与已有压缩测试；测试总数只增不减。

验证：全量 pytest **751 passed，50 subtests passed**；前端 JS、diff 检查通过。

真实模型的理由质量、内奸前期节奏与反贼隐匿表现，及 thinking 开/关各一局的对比，**未做、待用户统一实战验收**。没有用假网关结果冒充模型智能提升；不修改 thinking 默认以掩盖验证缺项。watchdog、无懈无限链与 L0 分层不变。

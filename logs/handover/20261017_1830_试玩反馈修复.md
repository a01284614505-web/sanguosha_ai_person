# 试玩反馈修复（战报、判定与摸牌动画、作弊模式、对局日志、身份标记）

日期：2026-10-17 18:30（+08:00）。执行模型 `claude-opus-5-5`。进入提交 `e506961`（main），分支 `feat/feedback-20261017`。

## 用户反馈与处理

| 反馈 | 处理 |
|---|---|
| 看不到战报 | 不是没做，是布局 bug：战报页只有一行 `1fr`，折叠的“决策轨迹”框被拉满整页，战报列表被挤到底部一小条。改为 `auto + 1fr`，轨迹展开最多占 45%。 |
| AI 思考时想一键看战报 | 有 AI 在思考时，牌桌右上（手机在中部右侧）出现“战报 ›”按钮，一点打开战报。 |
| 作弊模式角标 `>` | 新增最简作弊模式：大厅勾选，开局锁定。AI 武将框右侧出现“›”角标，点开看该 AI 最近的公开理由；理由也以 💭 写进战报。只给模型主动返回的理由，不给手牌和隐藏身份。作弊局照常记历史，但不计连胜与身份卡。 |
| 甄姬洛神看不到判定牌 | 洛神每一次判定都走判定框亮牌：黑色“生效·获得此牌”，红色“失效·洛神结束”。 |
| 无中生有、摸牌要有动画 | 新增引擎 `MainEngine.draw_cards()`：逐张走 `move_card`，牌堆空先洗牌，摸完发一次 `draw` 动画事件。摸牌阶段、无中生有、全部技能摸牌（经 `SkillManager.draw_cards`）、击杀反贼奖励都改走它。前端牌从中央飞向摸牌者：自己的显示牌面，别人的只显示牌背和张数（服务器不下发别人的牌面）。 |
| 关羽“武圣出杀太多/没次数限制” | 未复现。规则 AI 45 局探针（关羽分别在真人座位和 AI 座位，标准+军争牌堆）统计每回合有效【杀】次数，没有一次超过上限（排除诸葛连弩/咆哮）。代码路径：武圣候选与 `use_sha` 都检查 `sha_count < max_sha`，命中或被闪都计次。可能是被借刀/决斗/南蛮时用武圣“打出”杀（不计次数，符合规则）或装了诸葛连弩。现在战报能看了，下次遇到可以对照战报确认。 |
| 对局日志默认保存、无痕模式、日志管理、是否含思考 | 每局结束服务器自动保存到 `logs/runtime/game_logs/<档案>/<game_id>.json`（已加入 .gitignore）。全局设置新增“无痕模式”“日志包含思考过程”。新页面 `logs.html`：列表、查看（按轮次、按发生顺序穿插时间线/聊天/思考）、下载 JSON、单条删除、长按（手机）或“选择”按钮进入多选删除、全部删除。结算页加“本局日志”。日志里不含 API Key。 |
| 结算页手机上是电脑布局 | 原因：`grid-template-columns: 1fr` 的最小宽度等于内容宽度，620px 的统计表把整页撑宽。改为 `minmax(0,1fr)`，手机上统计表变成每人一张卡片。 |
| 阵亡后身份暗置 | 用户选择“做成开局选项”：大厅新增“阵亡身份暗置”，默认关（官方亮明）。开启后阵亡角色身份对真人和 AI 都不公开，奖惩仍按真实身份结算，对局结束后照常公开。 |
| 点问号身份牌手动标记 | 未公开身份的座位，点“?”弹出 忠/反/内/清除；标记只存在本标签页，不发服务器，虚线描边与真实身份区分。 |

## 实际改动

- 修改 `game_server.py`
  - `CustomHandler` 重写：新增 `_send_json` / `_read_json_body` 公共方法，统一 UTF-8 与 Content-Length。
  - 新增 `GET /api/decks`，返回全部牌堆定义与当前默认牌堆。
  - 重写 `POST /api/switch_deck`：走 `DeckManager.normalize_deck_id` + `switch_deck`，成功返回 `active_deck`、`deck`、`decks`；未知 ID 返回 400 且不改动默认值；非法 JSON 返回 400；异常信息带类型名。
  - `normalize_config` 增加 `deck_id` 规范化：旧 ID 迁移到 `standard`，未知 ID 直接拒绝开局。
  - 保持文件原有的**局部 import** 风格，未改动模块头部导入。
- 修改 `frontend/settings.html`
  - 牌堆选项改为由 `/api/decks` 动态渲染（标准 108 / 军争 53 / 标准+军争 161），页面不再自己维护牌堆清单。
  - 保存后同时写 `localStorage.active_deck` 与 `gameConfig.deck_id`。
  - 修复原有 HTML 结构错误：删除牌堆区外多开的一层空 `<section>`，「运行时数据状态」回到自己的容器。
- 修改 `frontend/game.html`
  - `onConnect` 中读取 `gameConfig.deck_id` 或 `localStorage.active_deck`，旧 ID 前端也做一次映射，在 `createGame` 前写入配置。
  - 取值在 `gameConfig` 可能被重建之前捕获，避免默认配置分支把选择冲掉。
- 新增 `tests/test_deck_api.py`（10 个用例）。
- 新增 `scripts/check_frontend_js.py`：提取 HTML 内联脚本交给 `node --check`，规避 PowerShell 内联引号破坏验证脚本的老问题。

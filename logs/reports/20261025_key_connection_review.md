# API Key 显示与模型连接验收

- 大厅和局内的 Key 输入框可点“查看/隐藏”，管理窗口中的 Key 编辑框也可查看。已保存列表显示首四位和末四位，中间遮盖。
- “测试连接”使用当前提供方、Base URL、Key 和模型，通过游戏相同的聊天接口发出小请求。成功与常见的 401、404、429、超时分别给出可读结果，服务器不回传 Key 或供应商响应正文。
- 运行中模型请求失败而降级时，牌桌给出一次提示，战报里可查失败状态码。HTML 响应声明 `Cache-Control: no-store`，新部署后页面不继续使用浏览器中的旧 HTML。
- Chromium 390×844 实点明文切换、连接成功及模拟 401、保存 Key 掩码；实际开局用模拟 401 接口验证牌桌降级提示。长提示按手机宽度换行。未使用真实 Key。

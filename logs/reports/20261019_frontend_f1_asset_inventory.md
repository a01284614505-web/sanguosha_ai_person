# F1 前端资源盘点

盘点时间：2026-10-19。只读检查，没有导入或复制资源。

`frontend/assets/heroes/` 有 27 张 JPG，共约 5.6 MiB。与 `data/heroes.json` 的 27 个内置英雄 ID 一一对应，缺失和多余文件均为 0。现有前端通过 `SGS.heroImageURL(heroId)` 固定请求 `assets/heroes/<heroId>.jpg`，不存在皮肤变体目录、ID 映射表、扫描接口或选择 UI。新导入英雄的 `image` 允许为空，当前组件会回退到名字首字。

这批资源可作为资源扫描的基线；皮肤 UI 接入前仍需服务端冻结可扫描目录、可选资源 ID、格式/体积校验、预览 URL、按需导入与保存/选择接口。不能直接把资源文件名当英雄 ID，也不能把用户的任意路径拼进静态 URL。

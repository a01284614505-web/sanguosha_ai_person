# 模型选择与连接资料库验收

## 改动

- “拉取模型”现在打开独立窗口，显示服务商返回的完整列表，可搜索、选择，也能关闭后手动输入。前端不再截取前 300 条，服务端不再截取前 500 条。
- 大厅 AI 配置、局内托管及局内调整 AI 的 API Key 和 Base URL 都增加“管理已存”。两种资料使用同一窗口样式，均可加备注、保存多条、选用、编辑和删除。只有点击“保存到本机”才写入浏览器 localStorage。Key 列表只显示末四位。
- 切换提供方时，资料库按当前提供方显示条目。

## 浏览器验收

- Chromium 390×844，大厅连接到本地模拟的 OpenAI 兼容服务：返回 700 个模型，窗口显示 `700 / 700`；搜索 `model-699` 后剩 1 项，点选正确填回表单。
- 两条 Key 和两条 Base URL 均可保存、选用；刷新页面后各两条仍在。局内实际开局后，托管窗口中验证了 Key 的备注修改、选用与二次确认删除，Base URL 管理窗口可打开。浏览器控制台无页面异常。
- Chromium 1280×800 核对 Key 管理窗口布局。
- `scripts/verify_project.py`：1084 个测试、93 个子测试通过，前端脚本与协议检查通过，两项 WebSocket 冒烟通过，输出 `VERIFY_OK`。
- 模拟服务只用于界面与完整列表验收；没有使用真实服务商账号。

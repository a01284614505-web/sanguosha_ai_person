### 需要从无名杀学习：

**1. 技能系统**
```javascript
// 无名杀应该是这样的（猜测）
skill = {
    trigger: { player: 'damageEnd' },  // 触发时机
    filter: function(event, player) {  // 触发条件
        return event.num > 0;
    },
    content: function() {              // 技能效果
        player.draw(event.num);
    }
}
```

需要学习：
- 触发时机有哪些
- filter条件如何写
- content效果如何执行
- 技能互动如何处理

**2. 卡牌系统**
```javascript
// 出牌流程（猜测）

```

需要学习：
- 响应机制如何实现
- 目标选择如何处理
- 距离判断如何计算
- 卡牌效果如何编写

**3. AI决策系统**

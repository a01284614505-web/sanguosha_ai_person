### Phase 3: AI决策完整接入 ⭐⭐⭐

#### 3.1 可选操作生成
```python
def get_available_actions(player):
    actions = []
    
    # 出牌阶段可以出的牌
    for card in player.hand:
        if can_play_card(player, card):
            actions.append({
                'type': 'play_card',
                'card': card,
                'targets': get_valid_targets(card)
            })
    
    # 可以发动的技能
    for skill in player.skills:
        if can_use_skill(player, skill):
            actions.append({
                'type': 'use_skill',
                'skill': skill
            })
    
    # 可以结束阶段
    actions.append({'type': 'end_phase'})
    
    return actions
```

### Phase 5: 音效系统 ⭐

#### 5.1 AudioManager
```javascript
class AudioManager {
    constructor() {
        this.sounds = {};
        this.bgm = null;
        this.enabled = true;
    }
    
    load(name, url) {
        this.sounds[name] = new Audio(url);
    }
    
    play(name) {
        if (!this.enabled) return;
        this.sounds[name]?.play();
    }
    
    playBGM(url, loop = true) {
        this.bgm = new Audio(url);
        this.bgm.loop = loop;
        this.bgm.play();
    }
}
```

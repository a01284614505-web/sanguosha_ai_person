## 📖 Game类结构（从index.js分析）

### 核心属性
```javascript
export class Game {
    players = []        // 玩家列表
    dead = []          // 死亡玩家
    playerMap = {}     // 玩家映射
    phaseNumber = 0    // 阶段编号
    roundNumber = 0    // 回合编号
    me                 // 当前玩家
    zhu                // 主公
    
    // 事件处理器
    globalEventHandlers = {
        _handlers: {},
        getHandler(name, type),
        ensureHandlerList(name, type),
        removeHandler(name, type, func)
    }
}
```

**关键发现：**
- 使用事件驱动架构
- 全局事件处理器管理所有事件
- 玩家通过playerMap管理
- 回合和阶段分别计数

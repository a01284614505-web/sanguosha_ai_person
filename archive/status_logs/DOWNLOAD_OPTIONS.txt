## ⚡ git clone太慢了，用这个方法！

### 方案A：使用wget下载ZIP（推荐）

```bash
cd /storage/emulated/0/Download/sanguosha/sanguosha_data

# 下载ZIP（约100MB）
wget https://github.com/libnoname/noname/archive/refs/heads/main.zip

# 解压
unzip main.zip

# 重命名
mv noname-main noname

# 清理
rm main.zip
```

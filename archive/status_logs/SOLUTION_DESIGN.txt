### 问题4: 世界书怎么生成？
💡 **三种解决方案**

#### 方案A: 自动从武将JSON生成（推荐）
武将JSON包含worldbook字段 → 自动合成世界书
```javascript
// 自动生成世界书条目
function generateWorldbook(heroData) {
    return {
        id: `hero_${heroData.id}`,
        keywords: [heroData.name, ...heroData.skills.map(s => s.name)],
        content: `
【${heroData.name}】${heroData.faction}
称号：${heroData.title}
体力：${heroData.max_hp}

技能：
${heroData.skills.map(s => `【${s.name}】${s.description}`).join('\n')}

${heroData.worldbook.summary}
${heroData.worldbook.skill_details}
        `
    };
}
```

#### 方案B: 手动编写Markdown
你在 `worldbook/` 目录手动写Markdown文件
```markdown

## 基本信息

```

### 问题6: AI怎么识别场上武将？
💡 **解决方案：动态注入世界书**

```javascript
// 游戏开始时，根据选中的武将自动注入世界书
function injectWorldbook(gameState) {
    const activeHeroes = gameState.players.map(p => p.hero);
    const worldbookEntries = [];
    
    activeHeroes.forEach(hero => {
        // 从武将JSON中提取worldbook
        const entry = hero.worldbook;
        worldbookEntries.push(entry);
    });
    
    // 注入到AI的system prompt
    const worldbookText = worldbookEntries.map(e => e.content).join('\n\n');
    
    return {
        role: 'system',
        content: `你是三国杀AI玩家。

当前在场武将：
${worldbookText}

请根据场上武将的技能制定策略。`
    };
}
```

**核心逻辑：**
1. 游戏开始 → 读取所有玩家的武将
2. 从武将JSON提取worldbook字段
3. 动态拼接成AI的system prompt
4. 每次AI决策时都带上这个prompt

这样：
- 不需要手动管理世界书
- 武将数据和世界书在一起
- 自动随将池更新

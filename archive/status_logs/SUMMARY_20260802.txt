
## 🔄 自动同步状态

**已实现：** ✅ 完全的双向自动同步

**工作原理：**
- 每5秒检查文件变化
- 项目 ⇄ Download 双向同步
- 后台持续运行（tmux）
- 添加武将自动同步

**使用方法：**
```bash
# 启动（一次性）
tmux new -s sync
bash watch_sync.sh
Ctrl+B + D  # 脱离，后台运行

# 检查状态
tmux ls

# 重连
tmux attach -s sync
```

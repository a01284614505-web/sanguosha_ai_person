#### 1. 手动同步（立即生效）

**功能：**

- ✅ 武将数据 → Download

#### 2. 自动同步（实时监控）
```bash
# 在tmux中运行

bash ~/sanguosha_tavern/watch_sync.sh
```

**功能：**
- ✅ 每5秒检查一次
- ✅ 项目文件变化 → 自动同步到Download
- ✅ Download新增武将 → 自动同步到项目

### 技术实现原理

```bash
# watch_sync.sh 核心逻辑
while true; do
    # 检查项目文件修改时间
    if find $PROJECT_DIR -newer /tmp/last_sync; then
        同步到Download
    fi
    
    # 检查Download新增文件
    if find $DOWNLOAD_DIR/wujiang -newer /tmp/last_hero_sync; then
        同步到项目
    fi
    
    sleep 5  # 每5秒检查
done
```

## 🚀 现在你可以做什么

### 1. 立即测试AI聊天
```bash
cd ~/sanguosha_tavern
bash start.sh
```
访问：`http://localhost:8888/chat_test.html`

### 2. 在文件管理器中查看所有文档
打开：`/storage/emulated/0/Download/sanguosha/sanguosha_data/docs/`

**重点查看：**
- **README_DATA_FOLDER.txt** - 数据文件夹使用说明
- **RESOURCE_CHECKLIST.txt** - 需要收集的资源清单
- **UPDATE_LOG.txt** - 最新功能说明

### 3. 开始收集资源
根据 `RESOURCE_CHECKLIST.txt`，你需要：

**高优先级（立即需要）：**
1. 5个武将头像（PNG格式）
2. 5个武将的数据（JSON格式）
3. 30张基本牌数据（JSON格式）

**示例位置：**
- 头像：放在项目的 `frontend/assets/heroes/`
- 数据：在 `sanguosha_data/data/` 创建JSON文件

### 4. 编辑数据文件
在文件管理器中：
1. 进入 `sanguosha_data/data/`
2. 创建 `heroes.json`
3. 用文本编辑器编写武将数据
4. 保存后复制回项目

## 🔄 文件同步

### 从项目同步到Download
```bash
bash ~/sanguosha_tavern/sync_to_download.sh
```

会自动同步：
- 所有.md和.txt文档
- 所有.sh和.py脚本
- data/目录的JSON文件
- worldbook/目录的Markdown文件

### 从Download复制回项目
```bash
cp /storage/emulated/0/Download/sanguosha/sanguosha_data/data/*.json ~/sanguosha_tavern/data/
```

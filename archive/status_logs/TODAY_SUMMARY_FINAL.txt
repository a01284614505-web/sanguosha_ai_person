```python
class Skill:
    - trigger: 触发时机
    - filter: 触发条件
    - cost: 发动成本
    - content: 技能效果
    - check_trigger(): 检查是否触发
    - execute(): 执行技能

class TriggerManager:
    - register_skill(): 注册技能
    - trigger(): 触发事件
```

```python
class CardSystem:

    - use_tao(): 桃
    - use_guohe(): 过河拆桥
    - choose_to_respond(): 响应选择
    - ai_respond(): AI响应
    - damage(): 伤害结算
    - enter_dying(): 濒死处理
```

💡 使用说明
  1. 从贴吧复制武将数据，粘贴到左侧输入框
  2. 点击"转换"或"使用AI转换"
  3. 查看右侧生成的JSON
  4. 确认生成的 ASCII 武将 ID 唯一；普通描述或 AI 转换技能默认仅作为资料展示
  5. 点击“导入到服务器”完成校验和原子保存，或下载 JSON 留作备份
  6. 在武将包列表中启用后，新开局会把该包武将加入将池；已开始的对局保持原快照

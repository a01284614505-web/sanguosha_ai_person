# 身份策略示例库

来源：`logs/handover/20261018_1435_AI智能提升与称号系统方案.md` 附录 A 的真人访谈。

每个身份一个 JSON，common.json 是对照他人话术的小段提醒。编辑后下一次决策即读取，不参与规则结算。每条必须有唯一 id、when 字符串列表、condition（条件）、option（可选做法）、say（可为空的台词）。不要把经验写成强制规则，不添加对手未公开身份/手牌真值。

when 全部满足才参与随机抽样：opening=前两轮，seat2=主公下家，lord_low=主公存活且体力不超过2，duel=只剩两人，threatened=近两轮有针对自己的公开敌对行为。空列表为通用经验。每次只抽3–4条自己的身份示例，另附一小段他人常见骗术，不整库塞入。

有多个可选行动的模型 AI 出牌时分两次实际请求：第一阶段只形成自己的判断与打法；第二阶段才给示例并最终选择操作。第一阶段即使返回 action_index 也不执行、不写笔记/打法；只有最终结果经引擎校验。响应、聊天、规则 AI 和只有一个候选时不增加这次复核；失败按既有规则 AI 回退，无递归重试。

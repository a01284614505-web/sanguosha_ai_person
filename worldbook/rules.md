# 三国杀规则总纲 —— AI世界书

## 回合阶段流程
准备阶段 → 判定阶段 → 摸牌阶段（摸2张） → 出牌阶段 → 弃牌阶段（手牌≤体力值） → 结束阶段

## 基本概念
- **体力/体力上限**：角色生命值，0或以下进入濒死
- **手牌上限**：默认等于当前体力值，弃牌阶段超出的牌需弃置
- **装备区**：武器/防具/+1马/-1马各限1个
- **判定区**：放置延时锦囊（乐不思蜀/兵粮寸断/闪电）的位置
- **距离**：座位距离 + 装备修正（-1马减距离，+1马加距离）
- **伤害**：默认1点；伤害来源为该牌/技能的使用者
- **濒死**：体力≤0时进入，需桃/酒救回，无人救则死亡
- **死亡奖惩**：反贼死→击杀者摸3张；忠臣死→主公弃所有牌

## 身份局规则
- **主公**：体力+1，胜利=消灭所有反贼和内奸
- **忠臣**：胜利=保护主公消灭反贼和内奸
- **反贼**：胜利=杀死主公
- **内奸**：胜利=消灭所有其他角色后与主公单挑获胜
- 身份在角色死亡时揭示

## 卡牌分类
- **基本牌**：杀(30)、闪(15)、桃(8)
- **非延时锦囊**：过河拆桥(6)、顺手牵羊(5)、无中生有(4)、决斗(3)、南蛮入侵(3)、万箭齐发(1)、五谷丰登(2)、桃园结义(1)、无懈可击(4)、借刀杀人(2)
- **延时锦囊**：乐不思蜀(3)、闪电(2)
- **装备/武器**：诸葛连弩、雌雄双股剑、寒冰剑、青釭剑、丈八蛇矛、贯石斧、青龙偃月刀、方天画戟、麒麟弓
- **装备/防具**：八卦阵(2)、仁王盾
- **装备/坐骑**：+1马(绝影/爪黄飞电/的卢)、-1马(大宛/赤兔/紫骍)

## 关键结算顺序
1. 判定 → 摸牌 → 出牌 → 弃牌 → 结束
2. 濒死结算：从当前回合角色开始逆时针依次决定是否出桃
3. 无懈可击可以抵消任何锦囊牌（包括延时锦囊），可被另一张无懈可击抵消
4. 伤害结算：确定伤害来源→触发造成伤害技→触发受到伤害技→扣减体力→检查濒死

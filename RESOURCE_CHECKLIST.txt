## 📝 游戏数据

### 1. 武将数据 (heroes.json)
📁 存放位置: `data/heroes.json`

每个武将需要包含：
```json
{
  "id": "caocao",
  "name": "曹操",
  "faction": "魏",
  "max_hp": 4,
  "skills": [
    {
      "name": "奸雄",
      "description": "当你受到伤害后，你可以获得造成伤害的牌。",
      "trigger": "DAMAGE_RECEIVED",
      "is_forced": false
    },
    {
      "name": "护驾",
      "description": "【主公技】当你需要使用或打出一张【闪】时，你可以令其他魏势力角色选择是否打出一张【闪】。",
      "trigger": "NEED_SHAN",
      "is_forced": false
    }
  ]
}
```

### 2. 卡牌数据 (cards.json)
📁 存放位置: `data/cards.json`

标准108张牌的完整信息：
```json
{
  "id": "sha_spade_7",
  "name": "杀",
  "type": "基本",
  "suit": "黑桃",
  "rank": 7,
  "effect": "对一名其他角色使用。你对目标角色造成1点伤害。",
  "target_rule": {
    "target_count": 1,
    "distance_limit": 1,
    "target_type": "other"
  }
}
```

### 3. 技能详细说明 (skills.json)
📁 存放位置: `data/skills.json`

27将所有技能的详细规则：
```json
{
  "skill_id": "jianxiong",
  "name": "奸雄",
  "hero": "曹操",
  "description": "当你受到伤害后，你可以获得造成伤害的牌。",
  "trigger_event": "DAMAGE_RECEIVED",
  "trigger_condition": "受到伤害后",
  "effect": "获得造成伤害的牌",
  "is_forced": false,
  "is_limited": false,
  "examples": [
    "曹操被【杀】造成1点伤害，可以获得这张【杀】",
    "曹操被【南蛮入侵】造成伤害，可以获得【南蛮入侵】"
  ]
}
```

## 📖 世界书内容

### 1. 游戏规则 (worldbook/rules.md)
📁 存放位置: `worldbook/rules.md`

需要包含：
- 基础概念（体力、手牌、距离等）
- 回合阶段详解
- 5人/8人身份局规则
- 2v2规则
- 斗地主规则
- 判定机制
- 濒死结算
- 奖惩机制

### 2. 武将技能详解 (worldbook/heroes_skills.md)
📁 存放位置: `worldbook/heroes_skills.md`

每个武将需要：
- 技能原文
- 详细解释
- 使用时机
- 常见组合
- FAQ（常见问题）

### 3. 卡牌详解 (worldbook/cards.md)
📁 存放位置: `worldbook/cards.md`

每种卡牌需要：
- 使用时机
- 目标要求
- 效果详解
- 与其他卡牌的互动

### 4. 通用术语 (worldbook/terms.md)
📁 存放位置: `worldbook/terms.md`

需要解释的概念：
- 弃置 vs 获得 vs 交给
- 判定机制
- 距离计算
- 伤害来源
- 转移伤害
- 拼点
- 翻面
- 连环状态

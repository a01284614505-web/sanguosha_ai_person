## 🔧 问题原因

1. **Python 3.14 太新** - FastAPI + Pydantic 不兼容
2. **Rust编译问题** - Termux上编译Rust组件很麻烦

## ✅ 解决方案

改用**纯Python实现**的测试服务器：
- 使用标准库 `http.server` 提供HTTP服务
- 使用 `websockets` 库提供WebSocket服务
- 不依赖FastAPI、Pydantic等复杂框架
- 只需要安装 `websockets` 一个依赖

## 🚀 现在启动服务器

```bash
cd ~/sanguosha_tavern
bash start.sh
```

服务器会自动：
1. 检查Python
2. 检查并安装websockets（如果需要）
3. 启动HTTP服务器（端口8000）
4. 启动WebSocket服务器（端口8001）

## 📱 访问方式

在手机浏览器打开：
```
http://localhost:8000
```

如果想从其他设备访问（同一WiFi）：
```
http://你的手机IP:8000
```

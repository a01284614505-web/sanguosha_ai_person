## 🚀 使用教程

### 第一步：启动服务器
```bash
cd ~/sanguosha_tavern
bash start.sh
```

### 第二步：配置API
1. 在浏览器打开 `http://localhost:8888`
2. 选择游戏模式（5人身份局等）
3. 为每个AI配置：
   - 填写API Key（必填）
   - API地址会自动填充，可修改
   - 选择模型名称
   - 调整温度参数（0-2）

### 第三步：使用API共享
如果多个AI使用同一个API Key：
1. 在第一个AI配置完成后
2. 勾选下方"将此API配置同步给其他AI"
3. 选择要同步的AI（如AI 2、AI 3、AI 4）
4. 配置会自动复制过去

### 第四步：测试聊天
1. 点击"开始游戏"
2. 选择武将
3. 进入游戏界面
4. 在右侧聊天区输入消息
5. AI会调用真实API回复你！

## ⚠️ 重要提示

### API Key安全
- API Key存储在浏览器localStorage
- 仅在客户端到服务器通信时传输
- 服务器不会持久化保存
- 刷新页面后需要重新配置

### 费用说明
- 每次AI聊天都会调用真实API
- 会消耗你的API额度
- 建议使用低成本模型测试
- 推荐：deepseek-chat (0.14元/百万tokens)

### 故障排查

**问题1：AI回复"（AI调用失败）"**
- 检查API Key是否正确
- 检查API地址是否正确
- 检查网络连接
- 查看服务器终端的错误日志

**问题2：AI回复"（此AI未配置API）"**
- 该AI的API Key未填写
- 返回大厅重新配置

**问题3：配置共享不生效**
- 确保先配置源AI的完整信息
- 勾选目标AI后，配置会立即同步
- 可以手动检查目标AI的配置是否已更新

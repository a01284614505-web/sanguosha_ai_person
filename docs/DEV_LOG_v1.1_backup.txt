## 🎯 项目目标

打造一个完整的三国杀游戏系统：
1. 玩家通过网页与AI对战
2. 所有AI对手由用户的API Key驱动
3. 支持8种AI Provider（DeepSeek/千问/OpenAI等）
4. 完整实现27将、108张牌、技能系统
5. AI聊天系统（游戏内对话）

## 🔑 关键技术决策

### 1. 为什么用纯Python WebSocket而不是FastAPI？
**原因：** Python 3.14 + Pydantic 2.x 兼容性问题，Rust编译失败
**解决：** 使用标准库http.server + websockets库
**结果：** ✅ 成功运行，功能完整

### 2. 武将数据和世界书如何融合？
**方案：** 一个JSON包含一切
```json
{
  "id": "liubei",
  "name": "刘备",
  "skills": [...],
  "worldbook": {
    "summary": "...",
    "skill_details": "...",
    "usage_tips": "..."
  }
}
```
**优势：** 
- 添加武将自动添加知识
- 禁用武将自动移除知识
- AI动态识别场上武将

### 3. 为什么不能完全在Download目录工作？
**限制：** Termux服务器必须在home目录运行
**解决：** 实时双向同步脚本（watch_sync.sh）
**效果：** 在Download编辑 → 自动同步到项目

### 4. 如何处理贴吧格式数据？
**工具：** hero_converter.py（Python脚本）
**功能：**
- 正则解析贴吧格式
- 自动生成worldbook
- 支持AI辅助转换（备用）
**使用：** 网页工具 hero_manager.html

```python
# hero_converter.py
def parse_tieba_text(text):
    """解析贴吧格式"""
    # 1. 按行分割
    # 2. 正则匹配字段（名字、称号、体力、技能）

```

**关键点：**
- 支持中文冒号和英文冒号
- 自动识别技能类型
- 名字到ID的映射表

### 2. 动态世界书注入
```javascript
// 游戏开始时
const heroes = players.map(p => loadHeroJSON(p.hero_id));
const worldbookText = heroes.map(h => 
    `【${h.name}】${h.worldbook.summary}\n${h.worldbook.skill_details}`
).join('\n\n');

const systemPrompt = `你是三国杀AI玩家。\n当前在场武将：\n${worldbookText}`;
```

**关键点：**
- 游戏开始时动态拼接
- 只加载场上武将的知识
- 每次AI决策都带上这个prompt

### 3. 实时同步逻辑
```bash
# watch_sync.sh
while true; do
    # 检查项目文件变化
    if 有新文件; then
        同步到Download
    fi
    
    # 检查Download新增武将
    if 有新武将; then
        同步到项目
    fi
    
    sleep 5
done
```

## 🆘 常见问题解决

### Q: 服务器启动失败
```bash
# 检查端口占用
netstat -tulpn | grep 8888

# 修改端口
编辑 test_server_simple.py
HTTP_PORT = 9999  # 改成其他端口
WS_PORT = 10000
```

### Q: WebSocket连接失败
```bash
# 检查ws_client.js中的端口
const wsUrl = `ws://${window.location.hostname}:8889`;
# 改成你设置的WS_PORT
```

### Q: 武将转换失败
```bash
# 检查格式
# 必须是：名字 势力
# 称号:xxx（中英文冒号都可以）
```
